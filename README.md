# ComWinTop

**Lokale Modbus-Integration für Home Assistant – ohne Cloud.**

Unterstützte CWT-Geräte:
- **TM-32DS:** 32 Temperaturkanäle (DS18B20)
- **MB-308N:** Digitale und analoge Ein-/Ausgänge (Ausgänge lesend)
- **MB-307D(II)-S:** Digitale Ein-/Ausgänge und Analogeingänge

**Funktionen:** Modbus TCP, RTU-over-TCP, RS485, flexible Abfrageintervalle, Kanalverwaltung und Kommunikationsdiagnose.

**Beta 0.1.0b30** für Home Assistant 2026.11+. Relais-Schreibbefehle (FC05) sind ausschließlich für MB-307D(II)-S über RTU-over-TCP nach ausdrücklicher Freigabe als Laborfunktion verfügbar. Nicht für sicherheitskritische Steuerungen.
